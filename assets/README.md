Place your real logo image files in this folder to replace the placeholder.

Recommended filenames:
- logo.png (raster, PNG)
- logo.svg (vector, preferred)

How to replace:
1. Put your `logo.svg` or `logo.png` into this `assets/` folder.
2. If you add `logo.png`, you can leave `principal.html` as-is (it now points to `assets/logo.svg`).
   - To use a PNG instead, either rename the file to `logo.svg` (not recommended) or edit `principal.html` change src to `assets/logo.png`.

Security: do not commit private keys or secrets here.
